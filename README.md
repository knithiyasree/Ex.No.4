## Use Case Selected from Unit 5

### Smart Irrigation System using IoT and AI

### Scenario

Agriculture faces challenges such as water scarcity, inefficient irrigation practices, and increasing energy costs. A Smart Irrigation System uses IoT sensors, weather data, and AI-based decision support to automate irrigation, reduce water wastage, improve crop yield, and enable remote monitoring.

### Target Audience

Farmers, agricultural engineers, smart farming companies, and water resource management authorities.

### Main Objectives

* Reduce water consumption by at least 25%.
* Improve crop yield through optimized irrigation.
* Enable real-time monitoring of soil moisture and weather conditions.
* Reduce energy usage in irrigation pumps.

---

# Prompt Design and Evaluation

## 1. Comparative Analysis Prompt

### Prompt

Compare drip irrigation and sprinkler irrigation for a smart irrigation system in terms of water efficiency, installation cost, maintenance, and suitability for different crops.

### Expected AI Response

* **Drip Irrigation:** High water efficiency, higher initial cost, low evaporation loss, suitable for vegetables and orchards.
* **Sprinkler Irrigation:** Moderate efficiency, lower initial cost, easier installation, suitable for lawns and cereal crops.

### Comparison Insight

Drip irrigation conserves more water, while sprinkler irrigation is cheaper to install for large open fields.

---

## 2. Experiential Perspective Prompt

### Prompt

As an agricultural engineer, describe your experience using AI-based smart irrigation systems on a farm.

### Expected AI Response

The AI system continuously monitored soil moisture and weather forecasts, automatically scheduled irrigation, reduced manual labor, and helped save water while maintaining healthy crop growth.

### Observation

The response reflects a professional perspective and practical field experience.

---

## 3. Everyday Functioning Prompt

### Prompt

Explain how smart irrigation technology works in everyday farming activities.

### Expected AI Response

Soil moisture sensors send data to a controller. The controller checks weather forecasts and automatically turns irrigation pumps on or off. Farmers can monitor the system using a mobile app.

### Observation

The explanation is simple and easy for non-technical users to understand.

---

## 4. Universal Prompt Structures

### Prompt 1

Explain smart irrigation in simple terms with an example.

### Expected Response

Smart irrigation is a system that waters crops only when needed. For example, if soil moisture becomes low, the system automatically starts irrigation and stops when sufficient moisture is reached.

### Prompt 2

Explain the working process of a smart irrigation system step by step.

### Expected Response

1. Measure soil moisture.
2. Collect weather data.
3. Analyze moisture level.
4. Decide whether irrigation is required.
5. Start or stop the irrigation pump.
6. Send status updates to the farmer.

### Observation

Structured prompts produce organized and educational responses.

---

## 5. Prompt Refinements

### Initial Prompt

Explain smart irrigation.

### Refined Prompt

Explain how an AI-based smart irrigation system uses soil moisture sensors, weather forecasts, and IoT communication to reduce water consumption in tomato farming. Include benefits and limitations.

### Improvement Observed

* More specific.
* Includes technology components.
* Includes application context.
* Produces a detailed and focused response.

---

## 6. Prompt Size Limitations

### Large Prompt

Provide 50 examples of smart irrigation applications in agriculture.

### Refined Prompt

Provide 10 examples of smart irrigation applications in agriculture at a time.

### Observation

Breaking large requests into smaller chunks improves response quality and reduces processing complexity.

# Evaluation Method – Rubrics

## Rubrics Criteria

| Criteria              | Excellent (5)      | Good (4)        | Average (3)          |
| --------------------- | ------------------ | --------------- | -------------------- |
| Clarity               | Very clear         | Mostly clear    | Somewhat clear       |
| Technical Accuracy    | Accurate           | Minor issues    | Noticeable issues    |
| Completeness          | Fully complete     | Mostly complete | Partially complete   |
| User Friendliness     | Easy to understand | Understandable  | Needs simplification |
| Relevance to Scenario | Highly relevant    | Relevant        | Partially relevant   |
